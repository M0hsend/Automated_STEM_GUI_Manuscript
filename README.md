# Automated STEM GUI manuscript - Analysis code
Code for the data analysis section of the automated NBED data collection manuscript.
For NBED datasets, raw data can be found here: 

**/dls/e02/data/2026/cm44133-1/processing/Merlin/Pt_NP_24Feb_Overnight**

Calibration gold data:

**/dls/e02/data/2026/cm44133-1/processing/Merlin/au_xgrating_150k/20260225_091202**


Notebooks for the analysis of NBED data perform the follwoing:

- Radial transform and analysis of the colelctive diffraction signal
- ACOM analysis in conjunction with particle size and morphology

Ptychography raw data can be found:

**/dls/e02/data/2026/mg44468-1/processing/Merlin/Pt_NP_Overnight_5March2026**

PtyREX package was used for reconstruction.
Included notebooks perform analysis on the reconstructed objects and probes.
